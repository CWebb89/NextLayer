two lines that make the engine build them.

Two engine pieces are our own code compiled into its build rather than variants of
its files: `src/qt` (the application) and `src/cli` (the headless slicing
harness).

## Data imported from another slicer

The printer catalog is generated from the profile bundle of a second AGPL-3.0
slicer, OrcaSlicer (https://github.com/SoftFever/OrcaSlicer, AGPL-3.0, © its
contributors). That project's license and the per-vendor license terms in its
`resources/profiles` remain in force for the data derived from it.

| In this tree | Comes from | Regenerated by |
|---|---|---|
| `upstream/resources/presets/vendor-catalog/` (generated, not committed) | OrcaSlicer `resources/profiles/<Vendor>/` | `tools/printer-catalog/generate.py` |
| `src/qt/assets/bed/voron24_350_plate.stl`, `voron24_350_logo.svg` | the Voron machine profile in the same bundle | copied by hand, one asset per machine |

The four OrcaSlicer calibration meshes that used to live in
`src/qt/resources/calib/` were removed on 2026-11-08: the calibration suite now
generates every test piece itself, and those meshes carry the reference project's
logo. Their provenance is recorded in `tools/calib-meshes/README.md`.

## Assets that are ours

`src/qt/assets/brand/next-layer-mark.svg` is ours.

No fonts are bundled. The interface uses whatever fontconfig resolves the
configured family to, and the icons are the **Material Symbols Outlined** font
installed system-wide (Apache-2.0, © Google LLC), drawn by name through its
ligature table — so an icon appears only if that font is installed, and the font
is never redistributed here.
